# Planificador-de-Tareas

**Planificador de Tareas** es una aplicación web interactiva diseñada para facilitar la organización personal y la gestión de proyectos diarios. Permite registrar, clasificar y estructurar tareas utilizando la **Matriz de Eisenhower** para priorizar de forma visual y clara las actividades según su nivel de urgencia e importancia.

### 🚀 Características Principales

- **Gestión Visual de Tareas:** Representación clara de tareas mediante tarjetas (`Cards`) dinámicas que incluyen nombre del proyecto, título de la tarea, descripción, fecha de entrega y estado.
- **Diseño Responsive:** Interfaz adaptable a dispositivos móviles y escritorio desarrollada con **Bootstrap 5** y un sistema de navegación por pestañas y paneles laterales deslizables (`Offcanvas`).
- **Paleta de Colores Personalizada:** Estilo visual accesible en tonos pastel para reducir la fatiga visual y ofrecer una experiencia de usuario agradable.
- **Validación y Alertas:** Manejo dinámico de errores y confirmaciones mediante alertas nativas de Bootstrap integradas con JavaScript.

### 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructuración semántica de la interfaz.
- **CSS3 & Bootstrap 5:** Maquetación responsiva, componentes visuales y diseño personalizado mediante variables CSS.
- **JavaScript (ES6+):** Manipulación del DOM, manejo de eventos y gestión del estado de la aplicación mediante arreglos y objetos. <br>
